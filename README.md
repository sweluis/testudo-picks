# Testudo Picks

A full-stack web application that helped students find the easiest general education required classes at the University of Maryland, College Park. The site did this by scraping classes from https://app.testudo.umd.edu/soc/ and ranking the currently available classes by average GPA. The application got both class and teachers' average GPA using PlanetTerp's API. The site received over 1,000 unique visitors before shutting down.

## Tech Stack

### Frontend

**Languages:** HTML, CSS, JavaScript

### Backend

**Languages:** Java

**Framework:** SpringBoot

**API Integration:** PlanetTerp API (https://planetterp.com/api/)

### Deployment

**Frontend:** Vercel

**Backend:** AWS EC2
